# Research & Upstream References

This directory contains research notes and prior art references used to design CodeForge AI:

- **Harbor** (`harbor-framework/harbor`): Canonical execution and evaluation harness for AI coding tasks (`task.toml`, `instruction.md`, `tests/test.sh`, `solution/solve.sh`).
- **SWE-bench**: Benchmark and execution patterns for evaluating LLMs on real software engineering repositories.
- **SWE-smith**: Repository-to-Docker environment construction and LLM-driven issue generation paradigms.
- **SWE-Gym**: Environment construction patterns and baseline stability lessons.
- **Aider**: Repository mapping using tree-sitter tag queries (`tags.scm`) and PageRank-weighted symbol graphs.
- **py-tree-sitter**: Multi-language AST parsing and symbol extraction engine.

> Note: Upstream repositories in `research/upstream/` are gitignored to preserve clean version control and maintain a lightweight distribution.
