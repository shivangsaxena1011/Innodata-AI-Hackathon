    How it works
    
      
    
        
    01
    Understand
    
          
    Pin the exact commit, parse with tree-sitter, rank symbols with PageRank, and build a reproducible Docker environment.
    
        
    02
    Generate
    
          
    Discover new behaviour across 7 archetypes, then write the spec, the hidden tests and the reference in separate model calls.
    
        
    03
    Prove
    
          
    Red → Green → Regression → Mutation. Tests must fail on the original code, pass with the reference, and catch plausible bugs.
    
        
    04
    Package
    
          
    Ship a Harbor task, confirmed by Harbor itself: lint clean, oracle reward 1, no-op reward 0.
